# Pragati Engineers – Precision Industrial Rollers

Official corporate website for **Pragati Engineers**, precision industrial roller manufacturer based in Ahmedabad, Gujarat, India (Est. 1985).

---

## 🌐 Complete Website Structure

- **Home Page (`index.html`)**: Features company hero slider, 6 distinct category flagship products (Tsudakoma cloth roll, Hard Chrome roller, Stainless Steel guide roller, MS Cooling roller, Aluminium guide roller, SS Scroll expander), 4 quality assurance pillars, manufacturing infrastructure summary, client testimonials, and inquiry call-to-actions.
- **About Us (`about.html`)**: Complete company background since 1985, vision, core values, leadership team, and manufacturing philosophy across our 2 specialized Ahmedabad units.
- **Products Catalog (`products.html`)**: Complete 25+ product technical catalog with interactive category filters:
  - Looms Cloth Rolls (Tsudakoma, Toyota, Picanol, Sulzer, Itema, Somet, Waterjet)
  - Hard Chrome Plated Rollers
  - Cooling & Heating Rollers
  - Stainless Steel Rollers (SS304 / SS316)
  - Aluminium Rollers
  - Scroll Expander Rollers
  - Mild Steel & Coated Rollers
- **Product Details (`product-detail.html`)**: Deep-dive dynamic technical page with interactive multi-angle gallery, full specification tables, target industries & applications block, dynamic features checklist, WhatsApp direct inquiry, and modal RFQ.
- **Infrastructure (`infrastructure.html`)**: In-house machinery specifications (VTLs, precision cylindrical grinding, dynamic balancing, pulsing welding).
- **Contact Us (`contact.html`)**: Full contact information for Unit 1 (Loom Cloth Rollers) & Unit 2 (Precision Rollers) at Swarnim Industrial Park, Bakrol Bujrang Road, Bakrol, Ahmedabad - 382430, plus direct phone, email, and inquiry form.

## 🚀 Vercel Deployment

This project is configured for seamless deployment on [Vercel](https://vercel.com):

1. **Framework Preset**: `Other`
2. **Root Directory**: `./` (repository root)
3. **Build Command**: `node scripts/build.cjs` (or `npm run build`)
4. **Output Directory**: `dist-home`
5. **Clean URLs**: Enabled (`/about`, `/products`, `/infrastructure`, `/contact`, `/product-detail`)

The build publishes all 6 HTML pages and web-optimized assets from `dist-home/` without any redirects, ensuring the full website is live and interactive.
